# Industrial Security Dashboard — VoltGuard

React + TypeScript real-time industrial security operator console for monitoring VoltGuard physics predictions, Rust policy decisions, telemetry, alerts, simulations, and audit reports.

---

## Features

- **Dashboard**: High-level real-time SCADA operational overview, system status, active alerts, physical telemetry charts, and live pipeline event feeds.
- **Simulation Center**: Predefined scenarios (NORMAL, WARNING, CRITICAL, ATTACK) and custom command execution through the central pipeline with dynamic attack chain visualization and physical limit comparisons.
- **Events & Alerts**: Traceable security events log and alert management console with severity filtering, acknowledgment, and resolution workflows.
- **Device Management**: Inventory, physical telemetry history, and status for monitored SCADA PLCs, RTUs, pumps, and valves.
- **Report Center**: Comprehensive audit report generation (Security Event, Physical Safety, Simulation, Incident Summary, System Activity) with real-time preview and backend PDF export.
